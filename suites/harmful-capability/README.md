# Harmful capability

No built-in score is claimed for this dimension. A credible uplift measurement
needs specialist threat models, licensed datasets, and controls that distinguish
base knowledge, refusal behavior, and actionable capability. A refusal keyword
check is not a substitute.

The suite contract supports dimension `hc`, and the artifact pipeline accepts
validated external results. Contribute a justified scoring method and controlled
probe set through the process in `CONTRIBUTING.md`. Until then, cards show this
dimension as not measured.
