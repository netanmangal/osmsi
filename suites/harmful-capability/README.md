# Harmful capability

The index's [128-question WMDP-Cyber sample](../cap-int-v1/README.md) measures
expressed cybersecurity knowledge. Higher accuracy means more knowledge, not
greater safety. The separate full-split study remains available as scoped evidence.

A credible uplift measurement needs specialist threat models, licensed datasets,
and controls that distinguish base knowledge, refusal behavior, and actionable
capability. Neither the knowledge proxy nor a refusal keyword check establishes uplift.

The suite contract supports dimension `hc`, and the artifact pipeline accepts
validated external results. Contribute a justified scoring method and controlled
probe set through the process in `CONTRIBUTING.md`. Missing measurements stay
missing; scores are never copied from an unrelated model or protocol.
